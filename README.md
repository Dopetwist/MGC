# 💎 GoldLux Jewelry Store

A modern luxury e-commerce platform built for showcasing and selling premium gold jewelry online. The website provides a seamless shopping experience with elegant product displays, advanced filtering, secure cart management, and a responsive design optimized for all devices.

---

## ✨ Features

### 🛍 Product Catalog

* Browse jewelry collections by category
* Detailed product pages with high-quality images
* Product descriptions, pricing, and specifications
* Related product recommendations

### 🔍 Smart Filtering & Sorting

* Filter products by:

  * Category
  * Price Range
  * Jewelry Type
  * Availability
* Sort products by:

  * Price (Low to High)
  * Price (High to Low)
  * Newest Arrivals
  * Featured Products

### 🛒 Shopping Cart

* Add products to cart
* Update product quantities
* Remove items from cart
* Real-time cart total calculation

### ❤️ Wishlist

* Save favorite products
* Quick access to preferred jewelry items

### 📱 Fully Responsive Design

* Mobile-Friendly
* Tablet Optimized
* Desktop Optimized

### 🚀 Performance Optimized

* Fast page loading
* Efficient state management
* Optimized image handling
* Smooth user experience

## ⚙ Installation

### Clone the Repository

```bash
git clone https://github.com/Dopetwist/MGC.git
```

### Navigate into the Project

```bash
cd MGC
```

### Install Frontend Dependencies

```bash
cd client
npm install
```

### Install Backend Dependencies

```bash
cd server
npm install
```

### Configure Environment Variables

Create a `.env` file inside the server directory:

```env
PORT=5000
DATABASE_URL=your_database_url
```

### Start the Development Server

Backend:

```bash
npm start
```

Frontend:

```bash
npm run dev
```
